# UI 需求（本阶段不实现页面）

## Edge：深色医疗实时监控

高对比低眩光布局。顶部显示设备、UTC/本地时间标识、连接状态、Mock 标志、最后更新时间。主区域包含摄像头预览占位、生理信号 ECharts 曲线、睡姿状态、姿态摘要；侧栏显示 Agent 日志、异常、CPU/内存/温度与待上传数量。

摄像头预览协议尚未定义，先显示明确占位，不占用摄像头。曲线从通道元数据读取名称、单位与采样率；未知时显示“未知”，缺失点断开曲线，不填零。展示 disconnected、无检测、模型未就绪、无数据、加载和错误状态。WS 断连显示过期数据提示及最后更新时间；重连去重并补查 recent。高频点限制显示窗口，不能无限增长内存。

## Cloud：浅色历史分析

浅色清晰布局。顶部设备和时间范围筛选；主体包括睡眠趋势、历史生理曲线、异常事件列表、多模态时间线；独立设备管理和分析任务区域。事件详情显示模型来源/版本、confidence、质量和时间，Mock 数据显著标记。

时间查询转换 UTC，界面明确显示当前展示时区；分页使用游标，过滤变化清空旧游标。任务展示排队/执行/成功/失败，结果关联原始事件；设备离线与历史数据缺失分开表达。空状态、部分上传失败、权限不足、服务不可用须有可理解提示。

共同要求：Vue 3 + Vite + TypeScript + ECharts；颜色不作为唯一状态提示，提供文字、图例、键盘可用控件与合理对比度。界面不给出未经验证的诊断结论，不把 Mock 数据展示成真实监测。
