# CIX 板端入口

`backend/app.py` 提供 FastAPI、SQLite、相机预览、Workbench 和云端任务领取。Qwen HTTP 规划、Skill 注册、执行与验证位于 `backend/sleep_analysis/`。`frontend/` 是 Vue 工作台，可从评审电脑运行。静态深度预处理与执行保留在 V0.3/V0.3.1 原路径，供资产校验和运行时定位。
